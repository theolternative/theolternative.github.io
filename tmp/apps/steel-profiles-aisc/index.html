Steel Profiles AISC

Steel Profiles AISC is a dedicated reference app for AISC steel sections with a table-first workflow optimized for fast engineering lookup.

It includes sortable steel tables, direct search by section name, and filtering to narrow results quickly. You can also open a full profile view with all main properties and convert values between measurement systems when needed.

On iPad, the interface provides an all-in-one table and detail view for quicker comparison during design checks, drafting, and classroom use.
